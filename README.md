# Wanderly — Travel & Tourism Homepage

> **"Discover More. Travel Further."**

A modern, clean, and fully responsive homepage for **Wanderly**, a fictional travel and tourism brand. This project is developed as part of the **Teknoppy Junior Web Developer Technical Assignment**.

---

## 🎯 Project Overview

The primary objective of this project is to provide an engaging, clean, and intuitive user experience that encourages visitors to explore travel destinations and plan their trips seamlessly.

### Core Priority
> **"A clean, responsive website that works well — not an overly complex project."**

---

## 🌟 Features & Sections

- **Header & Navigation**: Brand logo, primary navigation (`Home`, `Destinations`, `Packages`, `About`, `Contact`), and a prominent **"Plan Your Trip"** Call-to-Action button. Includes a fully responsive mobile drawer/hamburger navigation.
- **Hero Section**: High-impact travel imagery with the headline *"Explore the World, Your Way"*, descriptive copy, and an **"Explore Destinations"** CTA.
- **Popular Destinations**: 4 curated destination showcase cards (Bali, Dubai, Maldives, Switzerland) with destination imagery, brief highlights, and an *"Explore"* button.
- **Travel Packages**: 3 featured travel packages detailing package name, duration, starting price, and booking CTA.
- **Why Choose Us**: 3 core value propositions:
  1. *Best Travel Deals*
  2. *Handpicked Destinations*
  3. *24/7 Support*
- **Final Call-to-Action (CTA)**: High-conversion banner asking *"Ready for Your Next Adventure?"* with a *"Plan Your Trip"* action button.
- **Footer**: Brand summary, quick navigation links, contact details, and social media links.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic, accessible markup.
- **CSS3 / Vanilla CSS**: Custom responsive layout, CSS variables/tokens, flexbox, grid, and smooth micro-interactions without heavy external overhead.
- **JavaScript (ES6+)**: Interactive mobile navigation menu and smooth scrolling interactions.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Shanu-sp/Travel_website_tek.git
cd Travel_website_tek
```

### 2. Run locally
Open `index.html` directly in any modern browser, or run with a local live server:
```bash
# Using VS Code Live Server extension or npx serve:
npx serve .
```
